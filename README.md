# dependency-analyzer

Service-dependency graph with HTTP query API. Backend take-home.

Java 8, Spring Boot 2.7, Maven.

## Run

```
./mvnw spring-boot:run
```

First boot auto-seeds ~30k events to `data/events.jsonl` and ingests them.
Later boots load the snapshot.

## Test

```
./mvnw test
```

## Endpoints

```
GET /api/v1/services/{id}/reachable
GET /api/v1/services/{id}/dependents
GET /api/v1/path?from={a}&to={b}
GET /api/v1/cycles
GET /api/v1/critical?k=10
GET /api/v1/services/{id}/health?windowSeconds=300
```

Errors return `{"error":"...","message":"..."}` with 400/404. No stack traces.

## Observability

- `/actuator/health`
- `/actuator/prometheus` -- counters under `dpa.events.*`, gauges
  `dpa.queue.size` / `dpa.graph.{nodes,edges}`, timer `dpa.query.latency`.

## Config

All knobs under `app.*` in `src/main/resources/application.yml`. Defaults
in `AppProps.java`.

## Test data

Generated by `DataGen` on first boot. Deterministic for a given seed
(`app.generator.seed`, default 42). To use your own data, drop a JSONL
file at `data/events.jsonl` and set `app.auto-seed: false`.
